# BrandCast 노트북 디자인 가이드

## 1. 기준 디자인

모든 후속 노트북은 `프로젝트_소개/00_프로젝트_소개와_분석_페르소나.ipynb`의 시각 언어를 기준으로 한다.

디자인의 목표는 뷰티 브랜드의 세련된 인상과 데이터 분석의 신뢰감을 함께 전달하는 것이다. 보라·인디고를 분석의 중심색으로, 로즈를 브랜드와 위험 강조색으로 사용한다. 표와 본문은 장식보다 읽기 쉬운 정보 구조를 우선한다.

## 3. 표지와 핵심 질문

### 표지

- 첫 번째 셀은 대제목 표지로 사용한다.
- 배경은 `#312E81 → #7E22CE → #BE123C` 그라데이션을 사용한다.
- 모서리는 `24px`, 내부 여백은 세로 `44px`, 가로 `48px`을 기준으로 한다.
- 영문 프로젝트 라벨, 한국어 대제목, 영문 부제, 핵심 태그, 한 줄 메시지 순서로 배치한다.
- 태그는 반투명 흰색 배경과 둥근 캡슐 형태를 사용한다.

### 핵심 질문

- 두 번째 셀은 핵심 질문 전용 카드로 사용한다.
- 연한 바이올렛 배경 `#F5F3FF`와 왼쪽 `6px` 바이올렛 강조선을 사용한다.
- 질문 아래에는 이 질문이 지원하는 의사결정을 한 문단으로 설명한다.

## 4. 섹션 구성

- 대단원은 `## 번호. 제목`, 하위 단원은 `### 번호. 제목` 형식을 사용한다.
- 한 셀에는 하나의 중심 메시지를 둔다.
- 섹션 순서는 질문 → 입력 → 품질 확인 → SQL 처리 → 결과표 → 그래프 → 해석 → 결론의 흐름을 따른다.
- 긴 설명은 표, 짧은 목록 또는 강조 카드로 나누되 같은 의미를 반복하지 않는다.
- 장식용 카드는 표지, 핵심 질문, 중요한 판단, 최종 결론에만 제한적으로 사용한다.

## 5. 카드 의미 체계

| 카드 | 색상 | 의미 |
|---|---|---|
| 분석 안내 | 바이올렛 | 핵심 질문, 방법, 중요한 해석 기준 |
| 페르소나·브랜드 | 로즈 | 사용자, 제품, 브랜드 맥락 |
| 우선 후보 | 에메랄드 | 품질 기준과 분석 조건을 충족한 우선 검토 대상 |
| 대안 후보 | 블루 | 다른 강점이나 조건을 가진 비교 대상 |
| 주의·보류 | 앰버 | 표본 부족, 품질 문제, 사람의 추가 검토 필요 |
| 위험 | 레드 로즈 | 부정 감성, 제외 기준, 브랜드 위험 신호 |
| 최종 요약 | 다크 슬레이트 | 질문의 결론과 다음 단계 연결 |

카드에는 색상과 함께 `우선`, `대안`, `주의`, `위험` 같은 텍스트 라벨을 반드시 표시한다.

## 6. 표 디자인과 내용

- 기본 데이터표는 Markdown 표를 사용하여 GitHub와 Jupyter에서 모두 읽을 수 있게 한다.
- 열 제목은 짧고 구체적으로 작성한다.
- 숫자 열에는 단위와 기간을 제목 또는 설명에 표시한다.
- 입력 표본은 보통 5~10행, 지표·후보 표는 10~20행만 표시하고 전체 행 수를 함께 적는다.
- 후보 표에는 이전 단계 순위, 현재 순위, 통과 여부와 제외 이유를 포함한다.
- 실제 값이 없으면 빈 예시 수치나 가상 프로그램을 만들지 않는다.

## 7. 그래프 디자인

| 데이터 의미 | 권장 색상 |
|---|---|
| 전체 시장·비교 기준 | `#94A3B8` |
| 주요 후보 | `#4F46E5` |
| 보조 후보 | `#7C3AED` |
| 긍정·안정 | `#0F766E` |
| 주의·표본 부족 | `#D97706` |
| 부정·위험 | `#BE123C` |

- 배경은 흰색 또는 `#F8FAFC`, 격자선은 `#E2E8F0`을 사용한다.
- 제목은 질문형으로 작성하고 측정 단위, 기간, 모집단 또는 표본 수를 부제에 넣는다.
- 전체 시장은 중립 회색으로 낮추고 분석 대상 후보만 강조한다.
- 색상 외에도 라벨, 범례, 선 모양 또는 마커로 의미를 구분한다.
- 위험을 제외한 일반 순위에서 로즈 색상을 남용하지 않는다.
- 같은 질문의 노트북 표시본과 저장 PNG는 색상, 데이터, 제목과 기간이 같아야 한다.

## 8. 크기와 간격

| 요소 | 기준 |
|---|---|
| 표지 제목 | 약 `36px`, 줄간격 `1.25` |
| 카드 제목 | `18~25px` |
| 본문 | `15~17px`, 줄간격 `1.6~1.75` |
| 카드 모서리 | `14~18px` |
| 표지 모서리 | `24px` |
| 카드 내부 여백 | `22~30px` |
| 섹션 사이 여백 | 최소 `18~24px` |

화면 폭이 좁아도 읽을 수 있도록 카드가 여러 개인 경우 줄바꿈 가능한 레이아웃을 사용한다.

## 9. 문장과 표현

- 제목과 핵심 질문은 한국어로 작성하고 필요한 경우 짧은 영문 라벨을 보조로 사용한다.
- 분석 사실, 해석과 한계를 구분한다.
- 광고 효과, 매출, 구매 전환과 ROI를 입증하거나 예측한다고 표현하지 않는다.
- `최고`, `성공`, `효과적`처럼 실제 데이터로 확인하지 않은 단정 표현을 피한다.
- 후보는 `집행 확정`이 아니라 `우선 검토`, `대안`, `보류·추가 검토`로 표현한다.

## 10. 노트북 완료 전 디자인 점검

- [ ] 첫 번째 셀의 표지와 두 번째 셀의 핵심 질문 카드가 기준 디자인을 따른다.
- [ ] 인디고·바이올렛·로즈 중심의 색상 체계를 유지한다.
- [ ] 우선·대안·주의·위험 색상의 의미가 일관된다.
- [ ] 색상 외 텍스트와 라벨로도 의미를 이해할 수 있다.
- [ ] 표의 단위, 기간, 표본 수와 전체 행 수가 표시된다.
- [ ] Q1~Q6 노트북의 그래프가 계획된 두 개로 제한된다.
- [ ] 가상 결과나 확인되지 않은 후보가 포함되지 않는다.
- [ ] 결론 카드에 답변, 근거, 한계와 다음 단계가 함께 정리된다.
