# 데이터 보관 구조

`원본/`에는 RACOI에서 내려받은 응답을 수정하지 않고 보존합니다. 실제 원본 파일과 댓글 원문은 Git 추적 대상에서 제외합니다.

| 경로 | 내용 | Git 정책 |
|---|---|---|
| `원본/인터넷반응_주간/` | 최근 1년 인터넷반응 주간 자료 | 실제 파일 제외 |
| `원본/종합반응_월간/` | 최근 1년 종합반응 월간 자료 | 실제 파일 제외 |
| `원본/댓글반응_상세/` | 공개된 키워드·감성·연관어 원본 | 실제 파일과 원문 댓글 제외 |
| `원본/수집_메타데이터.jsonl` | 원본별 요청·형식·체크섬·결과 이력 | 실제 이력 제외 |

수집 URL, 시각, 기간, 체크섬, 행 수와 성공 여부는 우선 `수집_메타데이터.jsonl`에 다운로드 시도 단위로 남깁니다. 이 파일은 이슈 #5에서 `raw_ingestion_log` MariaDB 테이블로 적재합니다. 원본 Excel·JSON은 수정하지 않으며 GitHub에는 올리지 않습니다.
